# Drafting useful prompts and skills

- **Guidance:** For substantive prompt or skill changes; skip this procedure for obvious corrections. Reuse a suitable skill unchanged. Start from a recurring failure, an expert workflow, an incident or a real correction: name what the agent misses and the expected behavior difference. Research practitioners and credible alternatives when the missing judgment is uncertain; an observed correction does not require a new research project. Do not invent expertise through a generic persona. Name and description say what the skill does, when it applies and what distinguishes it from neighbors; check a realistic trigger and an unrelated negative. Encode concrete decisions, useful defaults, exceptions, observed gotchas and an observable success condition, not generic advice. Preserve user intent and authorization; reuse completed steps and ask only for missing facts that change the outcome. Keep core guidance sufficient to start; link substantial conditional detail and use existing scripts for repeatable deterministic work. Include a concise example or contrast only when it teaches a decision agents otherwise miss; explain why rather than encourage copying. Validate exported links and tool availability, then inspect a realistic changed behavior and a nearby case that should remain unchanged. Syntax checks do not prove behavior. Use the existing taste-review judgment and agent-management adoption routes; scale effort to the consequence.
