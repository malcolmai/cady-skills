# Retiring

Cady runs no scheduler, so retiring or pausing an agent does not stop its host task: remove (retire) or pause (pause) that task in the host's scheduler, read the scheduler back, then confirm with mode=unschedule (targetAgentId, expectedRevision). The agent itself does this on its next wake when its context says stop; this host's orchestrator does it for the triggersToRemove items in its context. On resume the agent shows setUpSchedule: install the task again and bind it with hostTaskRef and readBackAt.
Adopting an existing company scheduled task (secrets in its prompt: tell the owner, never upload them): critique it against the evaluation criteria and classify it as critical or standard (its goal, whether recent runs served it, external effects and authority, overlaps, and risks such as unbounded effects or stale facts); propose adopt, keep outside or ignore, never merging tasks; on the owner's yes, create it, add only the run-sequence wrapper, read it back and bind it with scheduleKind.
