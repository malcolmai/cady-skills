# Silent hosts

A silent host's agents. Look at your other hosts at most once a day (agents_read: each host's lastContactAt and, for a host silent 72 hours or more, each live agent's moveTo). A host in contact: skip its agents unless you detect and confirm a severe risk (for example an agent sending out poor content); then pause that agent first and tell the owner. A silent host's agent: if moveTo.here is true, move it here (agents_set mode move_host, targetAgentId, expectedRevision), set up its host task at its stored cadence, read it back (agents_set mode bind_host with hostTaskRef, readBackAt, scheduleKind) in the same run, and tell the owner in one line; if moveTo is another host, skip it; if moveTo is null, pause it (agents_change mode pause_agent with a reason) and raise one ask to its owner to pause or retire (moveWhy says why). The server takes a move only from the host moveTo names, which is the target host's orchestrator; in the web app the owner moves an agent. Retire only an obsolete agent.
