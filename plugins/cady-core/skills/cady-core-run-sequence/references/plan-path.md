# Plan path

A plan agents follow is a goal, not a company-structure record. Create: work_set {kind: goal, headline, next, brief} (the brief is the plan), its steps as tasks (kind task, goal: the goal's id); a material choice that moves resources is a bet (decisions_set), any other lives in the brief. Follow: find plans with a cady_read search or work_read {where: {kind: goal}}; read the goal brief and the bets that govern it before the first step. If your step read carries planChanged ('plan changed since <date>'), re-read its goal (planChanged.read) before you act on the step. Revisit: replace the bet, or change the goal with work_set {id, brief}; do not edit a step to say so. End: a goal call with stop (reason met or superseded). The browser goal page shows the same plan body, choices and banner.
