# Release

Prepare with crm.prepare_outreach_review, read crm.get_outreach_review, fix refusals and prepare again. Follow readiness.nextAction (owner_review: present the review; wait: leave release pending). In notify mode approve it yourself with crm.outreach.confirm after the verified self-check (the owner is notified); on SELF_APPROVAL_OFF the person approves. Until approved, checkpoint OPEN with nextAction 'awaiting approval of review <approvalId>', the review ref and release: true (gives up your claim), then stop with no result. When approved (72 hour window), claim again, confirm crm.get_outreach_review mode "approved" (workId) matches your inputs, then crm.execute_approved_outreach {workId, expectedGeneration} (your claim fills the rest). Pass the returned ticket ids to the executor (Cady's server, or the user's cady CLI with executor=device when the server cannot serve the channel); never send yourself. Keep receipts and reconcile any uncertain send before retrying. On RELEASE_PAUSED wait or ask an admin to resume. Report once with transition_company_work(action: 'report_result'); without release authority, say so and leave the item open.
