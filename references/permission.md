# Permission

Before drafting outreach, read crm.get_party with partyIds for up to 25 selected parties, or partyId for full tracks and recent notes. Resolve each party's marketing and non_marketing lanes, basis facts, suppression, verification, fit note and engagement. blocks: no_basis. Follow readiness.nextAction; record a missing basis with crm.apply_contact_basis {basisKind, cited source, partyIds}: relationship for a real relationship; legitimate_interest only for a business-role address with a relevant B2B offer where the jurisdiction allows B2B marketing email; consent where recorded. Apply by partyIds (up to 100) for the parties that qualify; use listId only when every eligible party in the List qualifies. Jurisdiction unknown or consent-first: apply none; exclude with the reason in the work result exclusions (a crm.update_party fitNote needs a cited source). Party-wide opt-out blocks both lanes and marketing opt-out blocks marketing. Destination suppression and active deferral block either lane; unacceptable email verification blocks email. For an unverified imported email, run the company's verifier on the host (MillionVerifier or pattern/MX evidence), then record it with crm.update_party mode verification using provider, optional checkedAt and results [{identifier, verdict, evidenceRef?}]. Catch-all is allowed but risky; invalid, disposable and unknown stay out. Cady makes no outbound verification requests. Record observed replies, meetings, calls, introductions and sign-ups with crm.record_interactions using source references only. A retry of a completed interaction call returns already_recorded per item; retrieve its receipt with crm.get_receipt, kind interactions and the identical first-call inputs. CRM derives engagement. Engaged or unverified parties never enter cold outreach. An opt-out in a note is not applied.
