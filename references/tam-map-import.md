# Reviewed CRM import

- **Steps:** For sourced accounts, create the segment List with crm.create_list. In the selected CRM use its reviewed import: for Cady CRM call crm.get_import mode "preview", then mode "prepare" with the exact preview, mapping and destination; prepare freezes review state but creates no parties or List membership. Then call crm.run_import mode "create" with previewDigest, jobId and reviewDigest from the reviewed preview/prepare, plus rows: "valid_only" and partySource; this persists the reviewed import job. Call mode "chunk" with that jobId/reviewDigest until its parties and List memberships are applied. Where the existing guarded crm.run_import mode="create_and_run" is available, pass previewDigest from preview, jobId/reviewDigest from prepare, the same CSV, mapping, kind, destinationListId and partySource, and rows: "valid_only"; use find_cady_tools {tool} if its exact schema or effect fields are unclear, then poll crm.get_import mode "status" with jobId and read completion; on refusal or unavailability use create/chunk. Each imported row needs a real email, LinkedIn URL or domain plus source; names alone are refused. Pass partySource on preview, prepare and create, use rows: "valid_only", and report skipped rows. Read final completion with crm.get_import mode "completion" and actual membership with crm.list_parties using its List selector/listId. Keep the completion receipt in evidenceRefs. If another CRM is selected, use its authorized reviewed route and keep it canonical.
