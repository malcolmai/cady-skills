# Reviewed CRM import

**Point:** Import sourced accounts only through the reviewed route and read back completion, so the List holds exactly what was reviewed.

- **Steps:** For sourced accounts, create the persona's List with crm_entities_write mode set_list. In the selected CRM use its reviewed import: for Cady CRM call crm_entities_read mode import_preview, then crm_entities_read mode import_prepare with the exact preview, mapping and destination; prepare freezes review state but creates no parties or List membership. Then call crm_entities_write mode create_import with previewDigest, jobId and reviewDigest from the reviewed preview/prepare, plus rows: "valid_only" and partySource; this persists the reviewed import job. Call mode "chunk" with that jobId/reviewDigest until its parties and List memberships are applied. Where the existing guarded crm_entities_write mode create_and_run is available, pass previewDigest from preview, jobId/reviewDigest from prepare, the same CSV, mapping, kind, destinationListId and partySource, and rows: "valid_only"; use find_cady_tools {tool} if its exact schema or effect fields are unclear, then poll crm_entities_read mode import_status with jobId and read completion; on refusal or unavailability use create/chunk. For new identities use real person email, LinkedIn or namespaced external identity, or company domain or external identity, plus source. For saved people map party_id to their returned partyId, optionally display_name, ignore other columns, and use destinationListId through the same reviewed import. Membership changes no identity, source, destinations or contact permission. Names alone are refused. Pass partySource on preview, prepare and create, use rows: "valid_only", and report skipped rows. Read final completion with crm_entities_read mode import_completion and actual membership with crm_entities_read using its List selector/listId. Keep the completion receipt in evidenceRefs. If another CRM is selected, use its authorized reviewed route and keep it canonical.
