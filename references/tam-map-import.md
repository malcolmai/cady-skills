# Reviewed CRM import

**Point:** Import sourced accounts only through the reviewed route and read back completion, so the List holds exactly what was reviewed.

- **Steps:** For sourced accounts, create the persona's List with crm_lists_set (name). In the selected CRM use its reviewed import: for Cady CRM call crm_lists_set with csv, mapping and kind (the preview), then crm_lists_set status "prepared" with the exact preview, mapping and destination; prepare freezes review state but creates no parties or List membership. Then call crm_lists_set with status "running", previewDigest, jobId and reviewDigest from the reviewed preview/prepare, plus rows: "valid_only" and partySource; this persists the reviewed import and starts it, and the server runs the chunks, so never advance chunks yourself. Show progress with crm_read mode imports (step "status", jobId); use find_cady_tools {tool} if an exact schema or effect field is unclear. For new identities use real person email, LinkedIn or namespaced external identity, or company domain or external identity, plus source. For saved people map party_id to their returned partyId, optionally display_name, ignore other columns, and use destinationListId through the same reviewed import. Membership changes no identity, source, destinations or contact permission. Names alone are refused. Pass partySource on preview, prepare and create, use rows: "valid_only", and report skipped rows. Read final completion with crm_read mode imports step "completion" and actual membership with crm_read using its List selector/listId. Keep the completion receipt in evidenceRefs. If another CRM is selected, use its authorized reviewed route and keep it canonical.
