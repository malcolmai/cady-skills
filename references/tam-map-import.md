# Reviewed CRM import

- **Steps:** For sourced accounts, create the persona's List with crm_lists_set or crm_lists_create. In the selected CRM use its reviewed import: for Cady CRM call crm_imports_read mode "preview", then mode "prepare" with the exact preview, mapping and destination; prepare freezes review state but creates no parties or List membership. Then call crm_imports_run mode "create" with previewDigest, jobId and reviewDigest from the reviewed preview/prepare, plus rows: "valid_only" and partySource; this persists the reviewed import job. Call mode "chunk" with that jobId/reviewDigest until its parties and List memberships are applied. Where the existing guarded crm_imports_run mode="create_and_run" is available, pass previewDigest from preview, jobId/reviewDigest from prepare, the same CSV, mapping, kind, destinationListId and partySource, and rows: "valid_only"; use find_cady_tools {tool} if its exact schema or effect fields are unclear, then poll crm_imports_read mode "status" with jobId and read completion; on refusal or unavailability use create/chunk. For new identities use real person email, LinkedIn or namespaced external identity, or company domain or external identity, plus source. For saved people map party_id to their returned partyId, optionally display_name, ignore other columns, and use destinationListId through the same reviewed import. Membership changes no identity, source, destinations or contact permission. Names alone are refused. Pass partySource on preview, prepare and create, use rows: "valid_only", and report skipped rows. Read final completion with crm_imports_read mode "completion" and actual membership with crm_parties_read using its List selector/listId. Keep the completion receipt in evidenceRefs. If another CRM is selected, use its authorized reviewed route and keep it canonical.
