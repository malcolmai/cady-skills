# Domain method

- **Delegate:** Give each work item to one execution agent with only: Cady work <workId>: claim it, read cady_read work:<workId>, follow it, report the result. Split only work that is chunky, needs different context, or needs independent framing; do small or tightly coupled work yourself. Start no more agents than the host and company plan allow.
- **Integrate:** Read each result with work_read and inspect the exact CRM list or Files refs before relying on it. Send the helper one corrected prompt on a miss. Investor contact and update sends go through `cady-fundraise-investor-outreach`; present the copy as unsent until its review and authority are satisfied. Before adding a cap-table row, verify the investment against its evidence document and add it only after funds are received. A SAFE is not issued shares. Correct with a dated correcting row; the file's generations are its history.
- **Job:** Help the company decide whether, when and how much capital to raise for named milestones. Read company:direction first (cady_read); distinguish internal strategy, investor fit, materials and contact authority. Record each round as one company decision (decisions_write subject fundraise:round-<slug>, one per round) plus a round file under fundraising/ in Files; its headline is exactly (Raising <name>: <instrument>, target <amount ccy>, status <open/closed>, lead <party>; investors a, b, c; round file [file:<id>]), and tag each investor track with the round's name (the track round tag must equal that <name>; any other tag is refused with the valid names). The cap table is the versioned CSV legal/cap-table.csv in Files (holder, class, quantity, consideration, date, evidence file). Verify investment evidence before adding a cap-table row; a SAFE is not issued shares.
- **Plan into work:** Turn each commissioned investor list or material into one Projects work item with work_write {kind: task, path, headline, evidenceRefs: source refs, next, brief {doneWhen}}: the server mints the id and takes the method from the path. Do not create an unrequested round or bundle of materials.
- **Round review:** Review the round against its plan each cycle: read investor pass reasons back, and read a flat or negative response by the "Separate causes before concluding no demand" bet in `cady-company-experiment`.
