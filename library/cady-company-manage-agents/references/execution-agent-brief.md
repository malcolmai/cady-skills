# Execution agent brief

**Point:** Brief a channel agent by reference, so it acts on current decisions and sends nothing without approval.

## Record

- Agent record: agents_set with this channel's own sub-goal as goal (it creates the agent when the sub-goal has none; a goal may have several agents). Name '<Channel> (<Company>)'; node: the channel's node under go-to-market; riskClass 'critical'; effects ['send'] (['publish'] for a posting agent); goal. State why it is its own agent: this channel has its own sending account and grant, so an account stop is isolated.
- Duties: one sentence of responsibility, then replies first, due follow-ups, today's first touches, report. Limits: day and week caps; 'prepare only until grant <grantRef> is active'; 'stop under `agent-stop.md`'; never research or rewrite the persona or offer: a missing brief ref is a stop and a report to channel strategy.
- Skills: that channel's execution skill only, plus the matching reply skill from the agent library when it owns the thread and the matching warm-email skill for email follow-ups. Pin host.installed {cady-id: version@library} from the SKILL.md headers for binding. Set triggers: []; recommend a cadence with why in the report, including how soon replies are seen.
- **First task:** one cycle of the channel's real work; state in the brief what it may release. Use work_set {kind: task, owner: the agent, goal: its sub-goal (a task takes its goal's node, so send no path), evidenceRefs for the List or partyIds, brief}, and name the channel's execution skill from the agent library in the brief as the one to load. The brief carries refs, never copies: no quotes, disqualifiers or offer text from the persona File or decisions; the channel execution skill reads them through profileRef. Include profileRef (persona File id), offerRef (accepted offer File or decision), listId or partyIds, segmentKey (the persona's key), cycleKey; angle and variant names and the assumption subject they test, not copy; senderLabel, grantRef (or grant terms to propose), voice and brand pack subjects; governing decision refs for strategy, targets and the pre-registered keep/scale/kill rule. Set brief.doneWhen to 2-5 reader tests tagged (check), (fresh) or (person), and brief.stopIf to the limit that ends the run early.
