# Plan path

A plan agents follow is a goal, not a company-structure record. Create: work_write with kind goal (the brief is the plan), its steps as tasks with parentId set to the goal, each material choice as a work_write or decisions_write or asks_write decision with parentId set to the goal. Follow: find plans with context_read area or work_read homePage {area: goals, areaPath}; read the goal brief and its linked decisions before the first step. If your step read carries planChanged ('plan changed since <date>'), re-read its goal (planChanged.read) before you act on the step. Revisit: supersede the decision, or change the goal; do not edit a step to say so. End: a goal call with stop (reason met or superseded). The browser goal page shows the same plan body, choices and banner.
