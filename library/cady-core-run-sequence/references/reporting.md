# Reporting a run

- **Exceptions:** For offline_evaluation or spotcheck only, record through manage_company_agent mode='record_run' using the current schema retrieved through find_cady_tools (tool: manage_company_agent, detail: schema). Preserve requestId, scenarioId, repetition, configurationRef, the Projects-derived evaluation runId, and actual output or outputRef; include only actually observed traces or usage in that schema. Evaluation reporting is exceptional and does not add a second ordinary run write. Do not add scheduled-slot or effect-receipt facts.
- **Output:** Lead with the result or material change, cite owner evidence, then state a conditional next step or exact blocker. File only what someone will reopen to use or check: a deliverable, or source evidence no owner record holds. Do not file process notes, local transcripts or repeated company context. Use a review packet only when the owner must approve exact materials together; otherwise keep any necessary memo brief and action-led. Local transcript review can diagnose retries, waste, missed instructions, tool misuse and behavior; persist only the material finding, evidence reference and correction in the existing owner.
- **Shape:** The ordinary reporting action is one close_company_work call. Each item carries claim, resultSummary, evidenceRefs when available and nextAction only when needed. A no-work execution is still a run and includes its observed times; a one-off with nothing material to report creates neither a run nor a task. Do not separately record the same run. Run metadata is optional: through this same close call, include observed start/end times, usage or output only when the host actually observed them and the owner schema supports them; omit unavailable facts. If the host provides no clock, register start at the beginning of the real attempt and finish when ending; these are attempt times, not effort duration. Never infer usage, execution start or skill use from a completion time or published version; identify only a skill version actually used. Point to the owner artifact by evidence ref; never duplicate its body in report metadata.
