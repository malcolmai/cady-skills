# Taste check: message

**Point:** Pass a message only when it reads as this sender writing to this person, so they have reason to reply.

- Tools: the outreach copy check (unfilled templates, empty subject or body, control characters, opt-out, sender misrepresentation, unsourced quotes).
- Tests: can they understand the actual purpose and reasonably respond (the recipient test)? Does it read as this sender typing to this person? Is the reason real and theirs, in words they use? Can they answer in a word?
- Pass when a fresh judge, shown this draft beside a real message from the sender, cannot tell which one the sender wrote. The outreach review is the person's own read; reply rates are the signal.
